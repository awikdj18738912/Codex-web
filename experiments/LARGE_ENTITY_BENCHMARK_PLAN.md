# 大规模多领域实体测试集建设方案

目标为至少 **1,000 个不同的标准实体**，每个都有真实音频和标准转录中的完整出现证据。优先做到 1,200–1,500 个，为审核删除不合格条目留余量。这里的数量是去重后的标准名称，不是重复提及次数、字典行数或音频条数。

本次先完成数据集、实验词库与评估输入；不改生产功能、不导入正式用户实体库。GPT-6 Luna 分工整理数据和审核候选，主代理制定协议、检查质量并汇总。

## 数据组成

| 数据来源 | 用途 | 质量边界 |
|---|---|---|
| AISHELL-1 测试音频＋现成 PERSON/ORG/LOC 标注 | 带实体边界的人名、机构、地名基础集 | 标注去括号后必须与标准转录一致；剔除历史已测录音 |
| Common Voice 中文测试集 | 化学、生物、科技、工程、医学、历史、体育等专业实体 | 词性或正则只生成候选，须保留完整实体及参考证据，经审核才入库 |
| SpeechIO 本地领域音频 | 法律、金融、科技、农业等术语 | 无原生实体金标，人工确认词条和边界；已见录音另列回归集 |
| WenetSpeech TEST_NET | 补充专业场景及负例 | 按标准参考筛选，不能把整套普通口语当专业语料 |
| CMeEE 文本实体标注 | 提供医学标准词源 | 只计在实际音频参考中完整出现的词；文本词表本身不计音频实体覆盖 |

MultiMed 曾发现音频和参考范围不一致的风险，本轮不作为主测试集数量来源；可另设待核查池，未核查条目不计入 1,000 个目标。

领域目标为医疗健康、计算机通信、工业交通、金融经济、法律政策、自然科学与化学、农业生态、历史教育、地理旅游、体育文化。至少 8 个领域有实际音频覆盖，争取 10 个；不靠改标签制造领域数。若某领域材料不足，明确记录缺口。

类型是另一个统计维度，包括 PERSON、ORG、LOC、TERM；至少 200 个实体应为专业术语，避免整套数据只有人名和地名。类型和领域只用于抽样与报告，不引入按类型的纠错规则。

## 样本与实体要求

1. 主目标标准名称符合当前中文复核能力：完整中文 2–24 字；纯外文或带标点但未有可核验中文别名的实体另列扩展集，不混入主覆盖数。
2. 不把“这个、医生、患者、治疗、公司、发展”等泛词当专业实体凑数。不把同一名称的多个领域副本、错误写法或重复音频重复计数。
3. 每个实体至少一条实际音频证据；能提供不同录音中的多次出现时优先保留。目标为 2,000–4,000 条正例音频，并增加至少 300 条词库未命中负例；最终按可用材料报告实际数量。
4. 负例另分“无目标词库实体”和“含未入库实体”，用于检查错误替换和错误插入。较短词条嵌在其他长实体内时不直接当独立目标。
5. 每条保留来源、原始录音 ID、参考转录、实体跨度、审核来源、音频路径／字节定位、时长、原始音频 SHA-256 与解码 PCM SHA-256。
6. 标准名称做 Unicode／繁简去重，保留原参考字形；不从 ASR 错误生成别名。合法别名须有独立来源证据。

## 避免测试偏差

- 不根据识别失败选择样本，不先挑“不开词库差、开词库好”的音频。
- 标准参考用于提前建库和最后评分，禁止提供给识别／候选确认流程。
- 主集排除已知实体评估中使用过的录音，并按 ID、参考及音频哈希核查；同来源／同说话人仍可能重叠，不宣称完全独立泛化。
- 建库、样本选择和审核完成后冻结输入及词库；未审核候选保存在独立文件，不计入已验证实体数。
- 基础金标与“参考匹配后人工审核”的标注分层报告，不声称所有音频已经逐条人工听审。

## Luna 执行分工

1. AISHELL 组：生成带原始 NER 边界的候选实体与新录音池，检查参考一致性，剔除已测 ID；不更改原数据。
2. 专业术语组：从 CMeEE 与真实音频参考交叉筛医学词，另整理各专业来源；保留词源、完整跨度与质量标签。
3. 跨域审核组：整理 CV／SpeechIO 的跨域术语，审核正则／词性候选，提供明确的领域依据；自动候选不能直接标成已审核。
4. 汇总组：合并和去重、选择覆盖全部词条的音频、加入负例、生成独立 SQLite 实验词库、冻结清单与报告。

各组只写自己的 staging 子目录和实验脚本，避免并发覆盖。输出根目录为 `results/large_entity_benchmark_v1_20261010/`。正式用户库保持原样。

## 后续评估矩阵

| 条件 | 检查内容 |
|---|---|
| 无实体库 | 原始基线 |
| 已有实体替换规则 | 大词库是否增加误改 |
| 替换规则＋实体原音复核 | 实体恢复、误改和等待开销 |
| 分领域词库／全部至少 1,000 实体词库 | 检索干扰、同音歧义及规模效应 |

同一音频共享初稿并固定其他处理参数。报告实体字面命中、遗漏／损失／额外出现、CER、候选覆盖、前 8 个提示词覆盖、复核次数和真实 ASR 耗时。只在确实执行后报告识别效果，构建完成不等于已经通过评估。

交付时先核验音频、转录、边界和覆盖数，再用少量跨域样本做运行检查；整套评估另按冻结输入逐批执行，禁止用烟雾测试效果代替全量结果。
