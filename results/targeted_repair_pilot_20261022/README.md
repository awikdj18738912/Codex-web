# 定向修复试验（2026-10-22）

## 边界

仅处理训练划分的风险筛查和独立修复候选；没有修改生产提示词或原始训练数据，没有启动新一轮微调。

`screen_dataset.py` 读取实际 SFT 导出并通过 manifest 的 output_index 和输入/目标 SHA256 逐条对齐。筛查命中表示需要复核，不表示错误；同一条可命中多项。

本轮规则覆盖英文实体/代码消失、阿拉伯数字值消失、部分时间限定词消失、目标中的显式改口词。不能覆盖全部语义问题；数字中文形式和单位换算可能误报，保留已撤回候选也可能漏检。

`pilot_sample_100.jsonl` 是确定性、按风险和场景分配的80条风险样本以及20条无标记对照。它不是随机总体质量调查，无标记也不等于无需精修。

## 流程

1. 本地 Qwen3-30B-A3B-Instruct-2507 AWQ4bit 在 GPU0 生成 KEEP / REPAIR / UNRESOLVED 提案。
2. 对可比较的结果进行随机固定顺序的匿名 A/B 独立语义审查；审查者看不到规则风险、教师决策和理由。
3. 主代理核对失败与有争议案例。只将确认改善的修订列入待应用清单。

教师 KEEP 不是通过率，REPAIR 不是修复成功率；规则命中率不是错误率。教师结果必须通过独立比较才可计为改善。输入歧义样本保留在隔离列表。

相关原项目流程：[AgenticASR pipeline](https://github.com/AnXMuy/AgenticASR/blob/main/pipeline/README.md)，包括生成、语义质检、去重和导出。本轮具体筛查和独立盲审是本地实验设计。

## 本轮完成结果

- 筛查84,875条，标记13,412条风险；规则命中不是坏数据率。
- 首个带风险提示的方案3条即暴露实体保护导致的错误，已中止并独立归档为 `aborted_risk_hints_*`，未混入后续100条。
- 不带规则提示的100条试验：85 KEEP、12 REPAIR；另3条JSON或决策/文本不一致。97条完成独立盲审和主代理裁定。
- 主代理裁定后的成对结果：新目标更好9、旧目标更好2、持平83、原文有歧义3。新目标仍有7条语义FAIL，不能把教师KEEP当作验收。
- 20条无规则风险对照均未改写；这不代表它们是真实“不需要精修”的门控负例。
- 对8条已指出具体缺陷的样本再由教师修订：3条达到本轮PASS；4条仍清理不全；1条原文理解有分歧。
- 完整核对后共保留8条改善候选，见 `verified_improvements_8.jsonl` 和同名CSV；已含上一步3条，不能相加为11条。
- 没有改写正式训练集；本轮没有重新微调。GPU0教师服务已关闭。

详细指标在 `final_report.json`。原始盲审保留不改；`lead_adjudications.jsonl` 记录每次调整，`pilot_review_final.jsonl` 与 `confirmed_review_final.jsonl` 为最终裁定。主代理区分了“撤回内容仍作为事实存在”和“有明确否定但改口过程没删净”，后者通常是MINOR。输入解释存在实质分歧的样本隔离，不强行生成金标准。

这轮证明筛查能找到风险，独立诊断后教师能修复部分样本，也暴露教师自审漏判和修订退回逐字口语的问题。它尚不足以支持整批自动覆盖训练标签。
