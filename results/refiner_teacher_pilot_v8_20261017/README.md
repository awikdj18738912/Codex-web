## 改了什么

1. **最终意图与口语干扰分开。** 教师选同一类种子中的一个主题，生成简短最终句子和改口候选。代码插入口癖、口吃、已知改口、拼字提示及误句号。独立的 Clean 调用仍需从输入恢复最终句子，完整样本的标签须与生成参照一致。
2. **保护规则只处理该保护的内容。** 修复星期多次改口和“一下”的误拦；拼音识别提示、短语重启等也有保守的英文删除例外。数值改变、实体改写及无依据丢失仍会拒收。提示没有恢复冗长的数字／英文保护段落。
3. **质检需有实际依据。** 使用源质量、意义忠实、清理完成三个有类型的结论，并要求再次清理目标后保持逐字一致。明显残留、实质文字新增、缺字段或调用失败不会放行。
4. **截断必须确实发生。** 代码先选择自然边界，再对齐已观察口语，只把该前缀发送给教师。完整句伪标片段、目标漂移、数字中间截断等会拒收。
5. **截断与完整句分别去重。** 补充片段曾因与完整输入相似而被旧去重误删。修复索引分组后，重新执行去重和导出，保留同一批19个已审核候选，没有修改其输入或标签。

该方式比自由编写口语故事更受约束，干扰模式也更固定。后续仍需用真实ASR输出和独立开发／测试集检验覆盖、自然度和泛化，不能以这些合成数据代替模型效果评测。

## 示例

```text
输入：呃，那个，用gRPC，不对，fetch()请求REST API获取数据。
目标：用fetch()请求REST API获取数据。

输入：嗯，那个，就是说，提，提醒我下午3点和王强，不对，李娜，最后改成，王强开会。
目标：提醒我下午3点和王强开会。

输入：嗯，京。东商城是主要的综合性电商平台之一，京东的京，商城的商。
目标：京东商城是主要的综合性电商平台之一。
```

片段示例的完整目标为“第三方API接口频繁超时影响了服务稳定性，建议立即排查。”，实际输入在“建议立即排查”之前结束，输出也只保留已观察的前一部分。不是把完整句仅标上 `is_fragment=true`。

## 文件

- `pairs_review.md`：最终19条输入、目标和片段参照，便于直接检查。
- `final/train.jsonl`：包含生成计划、数字规则和审查记录的完整数据。
- `final/pilot_sft.json`：19条 ShareGPT SFT 对话，学生目标仅为正文。
- `independent_review.json`：最终19条逐条审阅，含实际文本依据；旧18条报告保留在 `independent_review_before_finalization.json`。
- `summary.json`、`final_validation.json`：统计与最终导出、参照、片段对齐验证。
- `qc_controls.json`：4个错误标签与4个正确标签的实际教师质检结果。
- `fixed_checks.json`：20个固定开发检查，含未见姓名、英文标识符、否定和条件等。
- `regression_tests_final.log`：65项代码回归结果。
- `attempts.jsonl`、`supplement_attempts.jsonl`、`api_calls.jsonl`：拒收、补充和模型实际请求／回答。
- `source_snapshot/`、`provenance.json`：生成时的源码与哈希；之后仅调整去重及自然截断边界，见 `post_generation_source_changes.json`。
- `length_review.json`：教师tokenizer下，三段原始文本的token总和最大172；未套聊天模板，不是学生最终训练长度。

## 执行边界

使用本地 Qwen3-30B-A3B-Instruct-2507 4bit、单张 RTX 3090、vLLM 0.17.1。生成接口为 `http://127.0.0.1:8010/v1`，模型名 `refiner-teacher`，本次客户端超时600秒、并发2。

数据均为合成文本，ASR分支是文本截断与噪声模拟，没有在本批跑音频识别，也没有训练学生模型。9个场景在试验中均衡覆盖，生产默认场景权重、8%直通、10%误句号控制及20%ASR抽样配置不因此改变。

v3–v7及主动停止的v4/v5试验均保留在各自目录，不能将那些旧候选当作本轮合格数据。`run_round.py` 会向JSONL追加记录；复现时应建立新输出目录，不要直接覆盖本目录。
