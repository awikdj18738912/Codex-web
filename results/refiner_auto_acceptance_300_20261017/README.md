# 大批量自动验收改造

默认construction模式：教师先给最终意图，代码插入口语干扰，按构造记录重建校验后直接使用已知标签，省去第二次教师恢复目标。独立语义审查仍逐条自动执行，仍要求意图连贯、可恢复、忠实且干净。旧样本及teacher模式保留独立恢复路径。

新增pipeline/scripts/audit_dataset.py，在总流程第5步后全量检查ID、输入输出、规则处理、构造证明、片段边界及已存审查证据，输出SHA-256、分布、错误统计、固定seed抽检文件。异常返回非零，拒收日志默认保存。最终JSONL保留ID与完整口语，场景内数字ID加场景前缀。

## 检查

255条全量自动验收通过，结构／存储证据错误0；86项回归通过，8条依赖弃用警告。

开发期独立代理抽检60条，重点覆盖新增保留43条、各场景／改口及全部8条真实片段。初审56pass/4fail；三条流式片段尾逗号按允许恢复标点的任务定义复核为pass。一条共用“建议先”前缀的判断分歧：一人uncertain、一人pass，保守汇总59通过/1未决。原标签与判定保留；全部引用和ID已核对，引用修正备份独立保存。抽检不是均匀总体错误率估计，也不证明学生效果；生产无需逐条人工核对。

## 使用

```bash
python pipeline/scripts/audit_dataset.py \
  --input data/final/train.jsonl \
  --report data/final/acceptance_report.json \
  --sample-output data/final/review_sample.jsonl \
  --sample-size 300 --seed 20261017 --min-records 100000
```

总流程可加--min-final-records 100000，数量不足自动失败。尚未实现自动补足所有筛选及去重缺额循环，当前没有启动10万条生成。开发期／批次抽检发现系统性问题时，应修复逻辑并重跑批次，避免手改标签。

复放期间只有未被runner使用的独立验收脚本改了导入路径；复放后增加ID命名空间、数量门槛，不改变文字标签，已重跑全量验收与回归。源码快照见manifest.json。

参考官方[项目](https://github.com/AnXMuy/AgenticASR)及[质量控制代码](https://github.com/AnXMuy/AgenticASR/blob/main/pipeline/src/pipeline/quality_control.py)。85%属于本地固定输入复放指标。论文报告使用10万对，85%训练、15%验证；没有公开完整原始候选量／保留率。上游代码在生成后自动审查和去重，候选耗尽即停止，不保证单次运行最终满10万。
