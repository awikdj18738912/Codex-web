# 实体库首轮优化与部署验证

2026-10-03。已完成实体边界、候选确认、可信基线回滚和 Qwen ASR 上下文接入，并更新运行服务。

这次将实体库的两种职责分开：经过确认的别名继续直接规范；音近候选只供判断，不再先改字并当作可信实体保护。音频识别阶段现在也能读取当前领域的一小份标准名列表。

**代码行为**

- 新增独立中文词边界检查，使用私有 jieba 分词器，不把待匹配候选注入词典，避免候选自我证明。切进已有完整词、穿过分句标点、末尾为语法功能词或两字同音短词的候选保持原文。
- 精确匹配和模糊匹配都检查英文单词边界，CT 不会从 actually 中命中；完整的 __ENTITY_NNN__ 标记优先保留，不会因邻接英文字母被修坏。
- 模糊语义替换保持未掩码，Refiner 接收 observed/canonical/type 候选对。只有唯一且严格对应候选的 JSON 局部补丁能确认修改；自由文本、部分修改、越边界改写和高风险实体改名会被拒绝。
- 原始来源、可信别名基线和候选基线分开保留。失败时恢复可信别名基线，不把不可信改写留在回退结果里；规范记录只计已应用修改。匹配配置版本提升到 v2。
- Web 支持“词库辅助识别”开关。它把所选领域中至多16个标准名、最多1024字送到 Qwen 的 context，排除过短词及其它领域的通用词；提示不包含转写答案、别名错写或每条录音的参考文本。
- ASR 当前与 legacy_v1 启动接口接受 context，检查类型和2048字限额。上下文属于各自会话，在 VAD/长音频分段轮换中继续带入。返回实际应用标志和摘要，旧后端忽略时不会宣称已应用。
- 默认不开启音频上下文。可在页面勾选，或通过 --enable-entity-asr-context / ENTITY_ASR_CONTEXT_ENABLED=1 改默认值。普通文字实体规范不依赖这个开关。

**回归证据**

358项测试通过，9条来自第三方包的弃用提醒。新测试覆盖医学/新闻负例、英语词内命中、完整占位符、可信别名回滚、受限候选确认、Web上下文透传、旧模式兼容及服务端分段继承。

复用了此前430个真实医疗音频版本的固定ASR输出。新实体层没有再直接替换任何文本；旧版发生的短词和跨词误改已保留原文。这是保守策略的结果，不能解读为新增了430个术语纠正。

针对14个此前有问题的医疗音频版本，用真实 GPU Refiner 重跑无库和医疗auto两组，共28次完整Web会话。新医疗库输出与各自无库对照14/14一致，包含手术失败、手术是、手术视野、骨碎补及英语 actually 反例。没有关闭所有实体处理：可信别名和安全拼写格式仍保留，另有真实TAVI例子验证。

**真实ASR上下文对照**

复用一条已有开发录音的干净/加噪版本，加上16个医学与普通领域负例，共18个音频版本。每条重新发送真实PCM，各做一次 context off/on，交替顺序，总计36次真实Qwen识别；音频传输hash与原实验一致。

同一份名单来自运行中的医疗实体库，仅含TAVI手术，所有录音使用同一名单。不是按参考答案给每条录音挑词。

| 目标录音 | 无上下文的原始ASR | 有上下文的原始ASR |
| --- | --- | --- |
| 原始开发录音 | 凯比手术 | TAVI手术 |
| 10 dB 噪声版本 | 凯蒂手术 | TAVI 手术 |

目标术式在原始转写中由0/2变为2/2，16个负例都没有额外输出TAVI。开关也会影响其它字和人名；未出现该术式不等于没有其它误改。本轮是同一原录音两个版本的功能与回归实验，不能证明整个医疗领域的稳定提升。

配套字幕省略了较长英语片段，因此这一小集合的整体CER受参考缺标强烈影响；不使用其绝对值或下降幅度宣传总体听写准确率。完整逐条原始转写保留在 context_asr.jsonl，便于审阅其它变化。

实际8081 Web又发送同一段真实录音，分别关闭/开启词库辅助。关闭时 raw_text 为凯比手术，clean_text 由已确认别名变成TAVI手术；开启时 raw_text 已是TAVI手术，clean_text 保持规范，服务确认已应用1条医疗术语。本例常规Refiner调用从1次降为0次；这不是通用延迟基准。

**部署与使用**

更新后的ASR与Web已重新加载，原GPU、模型、tri_state门控、final-refinement off与zh-itn v90参数保持。重启时定位并清理了本项目旧ASR的残留vLLM引擎；后台启动改为setsid独立会话，解决临时启动命令结束后服务随进程组消失的问题。其它GPU模型进程保留。

刷新 http://127.0.0.1:8081 ，选择医疗领域，勾选“词库辅助识别”，再开始新会话。页面会显示实际应用的术语数。TAVI手术及已核实的完整短语别名在现用数据库中保持可用。

疑难片段按时间定位、自动二次识别属于下一阶段，本次没有新增自动留存/重识别整套流程。Qwen流式接口尚不提供逐词时间戳；后续需先建立音频片段与源文本的对应，再验证选择候选和回退策略。此次上下文接口与对照脚本为该实验提供了基础。
