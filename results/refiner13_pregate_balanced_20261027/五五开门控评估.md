# 五五开门控评估

评估日期：2026-10-27。已完成，退出码 0。未修改模型或接入线上服务。

## 数据与固定条件

保留原始 1,902 条测试输入（需修改 1,673 条、不需修改 229 条），从原测试配对的候选参考中确定性补入 1,444 条干净文本，最终两类各 1,673 条，共 3,346 条。新增参考并非新增生成或人工金标。

相同文本已去重，与门控训练、验证文本没有精确重复。此处未声称完成语义近重复隔离；错误输入与其干净参考可同时出现在本测试中。因此，这是已有测试的配对干净文本扩展，不是新收集的独立真实 ASR 测试。

门控仍是 870 万参数的原检查点，阈值固定为原验证集选出的 **0.03**。精修模型仍是两轮 LoRA checkpoint-1072。保留原 1,902 条精修输出缓存，对新增 1,444 条干净输入以同一提示词和贪心解码重新推理，新增部分批量为 16；未在本测试调阈值或训练。

## 门控结果

| 指标 | 结果 |
| --- | ---: |
| 需修改句召回率 | 99.28%（1,661/1,673） |
| 漏掉的需修改句 | 12 |
| 干净句直接放行率 | 31.02%（519/1,673） |
| 总调用减少比例 | 15.87%（531/3,346） |
| 仍需调用精修 | 2,815 |

531 条跳过样本中，519 条按候选标签无需修改，12 条为漏检。漏检分布与原测试相同：A03 2 条、C02 2 条、E05 5 条、E06 3 条；E05 召回 96.58%、E06 召回 97.95%。

## 最终精修效果

| 指标 | 全部调用 LoRA | 加门控后调用 LoRA |
| --- | ---: | ---: |
| 完全匹配候选参考 | 3062/3,346（91.51%） | 3067/3,346（91.66%） |
| 干净句被改动 | 71/1,673（4.24%） | 59/1,673（3.53%） |
| 归一化字符差异率（越低越好） | 0.5682% | 0.5702% |

门控避免了 12 条干净句误改，同时损失了 7 条原本精修正确的句子，净增加 5 条完全匹配，约提升 0.15 个百分点。字符差异率略升，说明不同质量指标并非一致改善。

## 判断

在五五开的构造分布上，独立小门控有一定收益：减少约 15.87% 精修调用，完全匹配率小幅上升。但它仍漏掉 12 条需修改句，不能认为已经验证适合上线。

相较原始测试仅节省 1.37%，本次提高主要源自干净句比例和来源变化，不是门控训练效果变强。所有标签仍来自候选参考，不能将匹配率等同于人工认可的正确率。

没有进行端到端延迟基准；调用减少 15.87% 不等于提速 15.87%。本次复用缓存和批量推理的耗时不能用于两种服务链路的速度比较。后续应在人工核验的真实 ASR 五五开样本上同时验证质量和耗时。
