# Qwen TTS 全量训练集门控试验（合成弱监督）

生成日期：2026-10-10。只使用固定文本数据的 `train` split；`dev`、`test` 未合成、未解码、未进入门控配对。

## 数据与产物

- 628 条 Qwen3-TTS 语音，记录的设备均为 `cuda:0`；音频文件齐全，TTS 请求零失败。
- 1,256 条 Qwen ASR 输出：每条训练音频各有 `clean`、`noise` 一个版本；628 个样本均被覆盖。
- 窗口精修配对：628 个案例、566 个录音组。
- 局部重复项审核配对：205 个案例、205 个录音组。
- 合并弱标签：833 条、576 个不同录音组；760 条可用于弱预训练。

主要文件：

- `tts.jsonl`：TTS 音频及来源记录。
- `asr.jsonl`：clean/noise 两种 ASR 转录及流式置信度载荷。
- `asr_clean_for_pairs_full.jsonl`：仅 clean 版本的配对输入。
- `pairs_full/` 与 `pairs_review_full/`：两条门控路径的冻结协议、运行结果、人工复核表和分组弱标签。
- `weak_gate_labels_train_all.jsonl`：合并后的 833 条弱标签，含 `pair_set` 来源字段。
- `weak_gate_label_summary_train_all.json`：合并标签计数与适用范围。

## 离线配对结果

窗口组中，当前门控在 628 个案例上记录了 279 次逻辑 Refiner 调用、158 次相对规则基线改变输出；始终精修组为 650 次调用、180 次改变。按未审核合成脚本计算的距离代理，当前门控有 0 次改善、132 次退化；始终精修有 0 次改善、151 次退化。

局部审核组中，当前门控与始终精修的输出一致；205 个案例触发 205 次 Refiner 调用，其中 127 次改变输出。距离代理改善 0 次、退化 127 次。

这里的距离参照是 `spoken_text`，即保留口吃、重复词等现象的原始朗读脚本；弱标签参照的是 `intended_text`，即期望的清理结果。成功删除口吃可能增大到原始朗读脚本的距离，同时恢复清理目标。因此，上述“零改善、退化”不能用来否定精修或弱监督原型训练，应分别报告转录忠实度与清理目标恢复情况。Qwen TTS 的音频是否忠实说出了朗读脚本也未经确认，这些数字不能解释为真实语音上的准确率或因果收益。

## 置信度覆盖情况与结论

ASR 日志包含 `qwen_vllm_token_logprob` 字段，但 1,256 条最终载荷的 `confidence_calibrated` 均为 false；其中 1,254 条的分数范围是 `generated_suffix`，没有覆盖完整最终文本。虽然每条至少有一个中间流式块带有 `full_text` 范围的分数，这些分数同样未校准。当前配对收集器在调用门控时传入 `confidence_metadata={}`，所以本试验没有测量置信度门控效果。

这批数据可以训练合成域的弱监督门控原型，用来预测调用精修的收益与伤害。标签来自规则基线与始终精修输出相对清理目标的比较，不是直接复制当前门控动作；但仍可能受到合成 TTS/ASR 误差和模板分布的影响。原型效果需要验证，当前数据不足以宣称真实语音上的部署效果。

建议先按 `intended_text` 补充精修评估，并按模板组隔离训练和验证案例，同一录音的不同窗口与审核案例不能跨组。随后用 760 条非 uncertain 弱标签训练轻量门控原型，与当前规则门控及始终精修比较。置信度可以作为后续特征实验，但必须对齐到对应文本，保留覆盖不足和未校准标记；未校准 logprob 可以作为模型输入特征，不应直接宣称为正确率或将 calibrated 标记改为 true。真实语音验收与阈值校准仍需少量可靠标注数据。
