# zh-itn v86 数量覆盖测试与修复

日期：2026-10-01。当前启用的规则库由 v85 升级至 v86。

## 新发现并修复的结构

普通量词的完整数量缺少覆盖，部分旧测量规则只允许较大的数字；约数的“多／余／来”及插在数词和“万／亿”之间的形式缺少统一解析；倍数过度依赖技术场景；原有范围保护还会阻挡“十六亿吨减少到了两亿吨”这样完整的同单位比较表达。

新增规则按数词、量词、数量上下文和完整端点结构解析，输出经规则审计的替换范围。小数、日期、型号、重叠量词及单位复合词继续检查边界。对同单位比较，保留“减少到了／下降到”等连接词，仅修改两个数量。单位不一致的疑似范围保留。

| 真实原文 | 新结果 |
| --- | --- |
| 两千多次 | 2000多次 |
| 十七条黄河 | 17条黄河 |
| 平时的三倍之多 | 平时的3倍之多 |
| 五十多座 | 50多座 |
| 七百多公里 | 700多公里 |
| 十三级泵站 | 13级泵站 |
| 两千多公里 | 2000多公里 |

| 十六亿吨减少到了两亿吨 | 16亿吨减少到了2亿吨 |
| 五个法器；十个 | 5个法器；10个 |

其他覆盖包括带数量上下文的份、册、双、支、杯等量词，以及“二十来座”“三百余条”“五十来万座”和小数量的件、辆、颗、箱、批。
