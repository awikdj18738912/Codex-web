# 场景词库修正版

本版修正测试词库的组织方式，保留原来的 2,000 条录音、参考标注和原始 ASR 基线。原始实体命中仍为 1,342/2,658（50.49%），没有重新筛选样本。

原“人名机构地名”同时混合实体类型和不同业务场景。新版将其中 727 条录音按遮蔽目标实体后的通用语义线索划分为 11 组；其余 26 个领域的词库保持字节不变。原混合库的 6,808 个不同实体全部保留在场景词库的并集中，也保留未入选录音提供的干扰词，没有按评测成功率删词或截断词库。

433 条录音仍缺乏充分场景依据，不能声称它们已经完成准确业务领域标注。场景标签是从参考文本离线生成的自动标注，目标实体会先被遮蔽；它们不是官方标签或独立盲测的自动场景识别结果。推理只使用冻结后的场景和词库路径。

新版数据位于 `dataset/`。词条来源、分组证据、构建源码及哈希分别保存在 `vocabulary_provenance.jsonl`、`route_annotations.jsonl`、`source_snapshot/` 和 `manifest.json`。37 个词库均可由当前默认匹配器加载，最大 4,177 词，目标实体覆盖检查通过。

重测目录为 `../entity_challenge_scene_eval_20261014_v2/`。为单独比较词库修正的影响，重测使用上一轮相同的实体模块源码快照；源码、PCM 和完整词库字节相同的 1,273 条复用上一轮输出与 HTTP 记录，改变词库的 727 条重新调用真实 ASR。神经 Refiner 和完整 Web 未运行。

工作区 `evaluate_current_entity_challenge.py` 和 `score_current_entity_challenge.py` 的默认 dataset 已指向本版。历史运行保留各自冻结脚本与数据路径。
