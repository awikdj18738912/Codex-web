# 数字重试策略实验

数字校验和数值保护保留；遇到数字校验失败且无占位符故障时，使用既有安全回退，省去模型重试。只在独立实验进程临时替换重试入口，未修改或部署生产代码。

这是此前混合句集合的针对性回放，无独立泛化或质量提升声明。安全回退保留数字，也可能保留未清理完的口语；未来某些重试本来能成功，这种策略会放弃该机会。

不含 ASR、模型加载或线上排队。每条窗口 3 轮，学习门控和实体库关闭。

本轮配对平均耗时从 501.29 ms 降到 412.56 ms，减少 17.7%；同轮纯模型平均 438.73 ms。上一轮不同计时批次的绝对值不直接作优化比例分母。
