## 审核与修复原则

- 输入最终意图可恢复、目标不正确：修目标，再由独立步骤审核。
- 输入含无法判定的同字面互斥修正、矛盾、不可恢复信息：隔离，不猜写。
- 保留有效数字/代码/英文；允许删除明确被撤回的旧值，不做机械全量保留。
- 引文不匹配、格式失败、截断、HTTP错误：fail closed并保留原因；不计作语义通过。
- 先校准调试集，冻结审核规则后跑留出集。只有五条已知FAIL/划分，仍需新样本复查漏放，不能称审核完全可靠。
- 后续输出新数据版本，保留source_id、原split、原输入/目标SHA、问题、修复与复审记录；修复后重新核对重复和划分污染。
