# 500条分项审核与修复试处理

状态文件：pilot500_results.progress.json。输出是研究候选，不是已批准训练数据。

## 数据与标准

从实际训练/验证SFT文件取样，保留原split、source_id、行索引、输入/目标SHA和分组信息。排除此前审查456条。uniform_random250条从剩余99396条中均匀抽取；risk_enriched250条另取100改口/否定、75中英混用、50长句、25括号风险。风险标签仅供分层，不是错误判定，不发送给教师。随机组与风险组分别统计；不能将两组混合比例当全量错误率。

主代理已核对 review_standard_review.md，三项分别判断原文可用性、有效信息忠实度和清理充分性。专业观点的外部真假不由精修擅自纠正；输入内未消解的数值矛盾须隔离；有效历史事实/否定不能因为旧实体出现就删除。英文名称/报错和编号保护遵守任务约定。

## 执行

两卡本地qwen38-teacher（8012/8013），每卡8个API并发；同一模型的独立调用不等于不同模型验证。

每条先做3次独立专项调用：source只看input，fidelity与cleanup各看input/target。原文不可靠的quarantine；证据/格式/接口失败或不确定者needs_review；原文明确、目标确有问题才生成修复候选。修复后重新调用fidelity和cleanup。任何候选的formal_training_eligible始终为false，待后续独立复核和主代理裁定。

20条旧开发难例的前置诊断仍有漏判，不能说明审核已可靠；因此这500条用来诊断并形成修复候选，不自动批准十万条全量处理。

## 独立检查

主代理预先盲审20条随机组样本，未读取教师评分、采样身份或原ID，判定保存在lead_prereview20_verdicts.jsonl。属于模型审查，不是人工金标。

教师任务完成后自动导出spotcheck_blind.jsonl：各组原通过候选抽查最多25条、已修复候选最多100条、隔离或待复核最多25条；与独立审查结果对照。盲审模型不读spotcheck_key或教师原判。未被抽查的修复不能因此自动获批。

summarize_pilot.py按采样组统计各专项、候选、修复尝试和错误，并对照主代理预审。完成后仍需分歧裁定，不用“教师通过数量”代替质量。

正式训练导出未覆盖；后续修复须输出新版本，并重新核对分组污染与重复。
