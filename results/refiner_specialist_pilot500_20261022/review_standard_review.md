# Input / target 语义复核标准（校准稿）

本标准用于逐条比较口语 input 与整理后的 target。旧模型判定、旧参考标签和单个词是否出现都不能代替语境判断。现有参考不是人工金标；本稿是统一复核口径，不宣称已获人工验证。

## 1. Source 有效性：input 是否足以支持可靠判断

判断 input 本身是否可理解、是否能辨认说话者最终要表达的内容。口语填充、重复、自我修正本身不使 source 无效；若有清楚的撤回与最终确认，应按最终确认理解。若指代、候选实体或相互冲突的事实在 input 内没有明确消解，无法确定最终意思，标为 REVIEW/uncertain，避免要求 target 猜测或强行选一项。明显残缺、不可理解或关键内容断裂，才判 source 无效。source 有效不代表 target 一定忠实或清理充分。

## 2. Fidelity 忠实度：target 是否保留 input 的最终有效意思

核对事实、实体、编号、数值、条件、否定、因果、请求意图及仍有意义的时间关系；不得补入 input 未支持的新事实。明确说过但随后撤回的候选通常不属于最终有效事实。若 target 把已撤回候选当成肯定事实，且遗漏或削弱了撤回/澄清，判 fidelity fail。

但不能仅因 target 同时提到旧候选和澄清，就自动判事实错误。若旧内容作为“先前说法/误判/已改正内容”的历史被清楚标记，且最终事实和否定关系都保留，事实忠实度可以通过；是否仍然过于冗长或保留了应清理的改口，另在 cleanup 判断。相反，真实有效的历史事实不能因它与当前状态不同就一刀删除，例如“之前联系过某售后，但现在改找另一方”；有意义的否定、对照、原因和纠错过程也应保留到足以维持原意。

## 3. Cleanup 清理充分性：是否去掉无用口语痕迹且不损伤内容

清理填充词、无意义的未完成起头、机械重复、已废弃候选的冗余复述；把最终陈述整理得清楚自然。cleanup 是独立维度：target 可能保留了全部事实和澄清，因此 fidelity 可过，但仍大量照搬“候选—否定—再确认”过程，导致目标不够简洁或仍突出已放弃方案，此时可判 cleanup fail/minor，而不必声称它“事实错误”。

清理时保留必要的否定和澄清，使读者不会把已撤回内容误读为事实；也保留有效历史信息及有意义的否定对比。不要把“删掉所有旧实体”当作通用修复。遇到改口后目标仍含旧候选但上下文无法判断它是历史叙述还是未清掉的主张时，标 REVIEW 并说明歧义。

## 复核输出建议

source validity、fidelity、cleanup 分别判定并分别写证据；不要用其中一项替代另一项。PASS 表示该维度符合；MINOR 表示局部瑕疵但核心信息清楚；FAIL 需指出具体遗漏、冲突、无依据添加或清理缺陷；REVIEW 用于 source 歧义或证据不足。引用 input/target 中的具体短语作为依据。编号、英文报错、命令和专名应逐字核对，不能把翻译后的意思等同于保留原字符串。所有结论均为模型/审查建议，除非另有人工流程确认，不称为人工金标。
