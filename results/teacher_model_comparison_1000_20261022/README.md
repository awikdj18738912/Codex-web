# Qwen3-30B教师重生成对照（1000条）

## 目的

用本机 Qwen3-30B-A3B-Instruct-2507 AWQ 教师，对固定的1000条训练输入重新生成精修目标；与数据集中已有目标做A/B盲审，评估是否值得批量替换。旧目标与新目标在审核前随机标为A/B。

## 数据和生成

- 样本来自训练划分，不使用验证划分。
- 风险分层：意外断句候选100、连续改口200、中英技术实体150、数字100、单次改口150、干净/免改100、其他清理200。
- 九个场景均覆盖；这是诊断样本，比例不能外推到全量训练数据。
- 生成模型：本机 `/home/aim0/data/models/ASR/Qwen3-30B-A3B-Instruct-2507-AWQ-4bit`。
- 两组输出使用当前 `pipeline/configs/prompts_clean.json` 中文精修提示词。
- 教师成功生成1000/1000条，失败0条；总耗时约22分13秒。
- 621条新目标与旧目标完全相同，379条有变化。

## 200条盲审结果

主审调整两条边界判定后，结果如下：

| 指标 | 旧目标 | 教师重生成目标 |
|---|---:|---:|
| 通过 | 189 | 185 |
| 轻微问题 | 7 | 11 |
| 明确错误 | 4 | 4 |

逐条偏好：旧目标胜15条，重生成目标胜11条，平局174条。**旧、新目标的4条明确错误是同一组，重生成没有修复其中任何一条。**主要问题是：已撤回候选仍留在输出、英文技术实体被翻译、人物关系被改写。

20条干净输入控制中，教师重写了4条；复核样本里这4条均可接受。新旧目标差异多数很小，常见于标点、连接词或句式调整。

## 决定

这次不能支持把整批旧目标替换为同一教师、同一提示词新生成的目标。模型重新生成改变了379条，但盲审没有显示语义质量提升，主要错误仍然存在。保留新旧目标和审核理由，后续只对明确失败类型调整提示词与审核规则，再做小批对照。

这200条按风险分层抽取，且由模型辅助审核，不是全量错误率或人工金标。它适合决定下一步的数据修订，不代表学生模型的真实语音表现。

## 提示词v2对照

对同一批200条输入，用同一Qwen3-30B教师比较当前提示词v1与一版更明确强调撤回候选、英文技术实体、主体关系和干净文本不改的v2。v2盲审结果：v1通过193、轻微6、明确错误1；v2通过187、轻微8、明确错误5。逐条胜负v1胜50、v2胜27、平局123。主审将1条双方轻微保真问题从初审标签中修正。

这说明把规则继续写长没有带来改善，v2在路线名、地点实体、时间限定和不确定性上反而出现新错误。当前不采用v2，也不全量替换旧目标。下一轮优先用程序检查目标是否改动可识别的专名、代码和数字，再让独立审核集中处理即时改口和主体关系。

- `prompt_v2_comparison_200.xlsx`：v1/v2盲审表。
- `prompt_v2_comparison_report_final.json`：v2最终汇总。
