今天我们换一种方式认识免疫系统。先不背细胞名单，而是假设一处黏膜屏障受到损伤，少量微生物进入组织。身体需要完成几件事：发现异常，把消息传出去，组织防御，最后让反应适时结束。不同细胞会在这些环节中接力，但它们并不是排好队、一个接一个才开始工作。很多过程会同时发生，而且前一个环节的强弱，会影响后续反应的方向。

最先讨论的是三类粒细胞。嗜中性粒细胞常常参与感染早期的防御，可以向炎症部位募集并参与吞噬和杀伤。嗜酸性粒细胞与寄生虫防御、部分过敏性炎症有关。嗜碱性粒细胞也参与过敏相关反应，并能释放影响周围细胞的介质。记忆这三个名称时，要把嗜中性粒细胞、嗜酸性粒细胞和嗜碱性粒细胞分别对应到具体情境，不能只因为都叫粒细胞，就认为它们的功能完全相同。

接下来，我们看看淋巴细胞中能够迅速作出反应的成员。自然杀伤细胞能够识别某些异常细胞，并通过多种机制参与清除。讨论自然杀伤细胞时，既要看促进反应的信号，也要看限制反应的信号。一个细胞是否受到攻击，往往取决于多类信号的综合结果，而不是某个单一标志出现以后就必然被清除。

与自然杀伤细胞相邻的一个学习主题，是固有淋巴样细胞。这里重点介绍三个常见的辅助样亚群：I L C 一、I L C 二和I L C 三。为了避免把名称背成一个连续的字符串，我们把它们分别放进句子里。I L C 一参与某些一型免疫反应；I L C 二与二型免疫反应及组织环境的调节有关；I L C 三在黏膜防御和屏障稳态中具有重要作用。这些描述只用于建立初步联系，不能替代对具体组织、刺激和疾病背景的分析。

假设研究者从肠道样本中观察到一组固有淋巴样细胞，他接下来需要判断这些细胞属于哪个亚群。不能仅凭样本来自肠道，就把所有细胞都标成I L C 三；也不能看见某一种细胞因子，就完全排除I L C 一或I L C 二。细胞分类需要结合多项证据。再次读这三个名称时，我们仍然分别说I L C 一、I L C 二、I L C 三，不把其中的字母省略，也不把后面的数字当成同一个编号。

另外还有一个容易混淆的名称，叫固有样淋巴细胞。固有样淋巴细胞与固有淋巴样细胞并非可以直接互换的两个词。一些具有较快反应特点的T细胞和B细胞，可以放在固有样淋巴细胞的讨论框架下。例如，部分伽马德尔塔T细胞和B一细胞常被用于说明这种特点。这里的重点是理解分类依据，而不是看见名称中有固有两个字，就认定它们属于完全相同的细胞群。

说到T细胞，我们需要区分伽马德尔塔T细胞与阿尔法贝塔T细胞。它们名称中的希腊字母，反映了T细胞受体链的类型。多数常规T细胞属于阿尔法贝塔T细胞，而伽马德尔塔T细胞具有不同的识别特点和组织分布。比较这两类细胞时，既要保留伽马德尔塔T细胞和阿尔法贝塔T细胞的完整名称，也要把受体结构、抗原识别方式和功能情境分开讨论。

T细胞受体负责参与抗原识别，但识别以后如何把信息传到细胞内部，需要其他分子共同参与。与之对应，B细胞受体能够结合相应抗原，也依赖相关信号分子启动后续过程。T细胞受体和B细胞受体都与抗原识别有关，却不能因此认为它们识别抗原的方式完全一致。在记录实验结果时，如果讨论的是T细胞受体，就不应因为附近出现了B细胞，而把受体名称顺手改成B细胞受体。

下面转向B细胞。按照常用的学习框架，可以比较B一细胞和B二细胞。B一细胞与某些天然抗体及较快的防御反应有关，B二细胞则是讨论常规适应性体液免疫时的重要对象。不过，B一细胞和B二细胞不是一号细胞先发育、二号细胞后发育的简单顺序。名称中的数字用于区分细胞类别，不能随意省略，也不能因为数字相近就混用。

再从发育角度看，祖B细胞处于B细胞发育的较早阶段。祖B细胞需要经历后续发育和选择，才能形成具有相应功能的成熟细胞。初始B细胞则通常指尚未被相应抗原激活的成熟B细胞。祖B细胞和初始B细胞描述的是不同阶段，因此不能把初始理解成所有发育早期阶段的统称，也不能把祖B细胞直接等同于已经成熟的初始B细胞。

当合适的抗原刺激和其他必要信号到来时，初始B细胞可以被激活，形成活化B细胞。活化B细胞可能走向不同的后续命运，其中一部分参与生发中心反应。生发中心B细胞在特定的组织环境中经历增殖、选择等过程。为了理解这条路径，我们可以连续比较初始B细胞、活化B细胞和生发中心B细胞，但不能把这三个名称当成同一细胞状态的三种写法。

免疫反应之后，一部分细胞可以形成记忆性B细胞，另一部分可以向分泌抗体的浆细胞方向分化。记忆性B细胞有助于机体在再次遇到相关抗原时作出反应，浆细胞则承担大量抗体分泌工作。判断一个样本中是否存在记忆性B细胞，不能只看抗体浓度；判断浆细胞的数量和状态，也需要结合适当的检测证据。

这里插入一个名称辨析：浆细胞样细胞与浆细胞不能只凭字面相近就合并。浆细胞样细胞这个表述，需要联系具体的细胞分类、形态描述和实验背景理解。样字可能是在描述某种相似性，并不自动意味着它就是能够大量分泌抗体的浆细胞。整理转录或实验笔记时，尤其要保留浆细胞样细胞中的样字，不能为了缩短名称而删掉。

不同细胞之间怎样传递更有针对性的信息？一个关键环节是抗原提呈。抗原提呈细胞处理抗原，并通过相应分子向T细胞展示信息。人类白细胞抗原，也就是常说的H L A，是这一主题中的重要名称。讨论人类白细胞抗原时，需要区分不同类别和具体功能，不能只把它理解成某一种细胞独有的标签。抗原提呈细胞、人类白细胞抗原和T细胞受体，可以放在同一识别过程里联系学习。

另一个名称是人白细胞分化抗原。我们在了解白细胞表面分子和命名历史时，会遇到人白细胞分化抗原以及相关的国际协作研究。分化群是CD的一种中文表述，也常见分化簇的译法。分化群编号用于标记相应分子，并不等于细胞本身的编号。人白细胞分化抗原与人类白细胞抗原虽然中文名称相近，但不能将前者相关的H L D A和后者的H L A当成同一个缩写。

以F A S为例，它也被称为C D 九十五，是参与细胞死亡信号的重要受体之一。细胞表面的F A S与相应配体发生作用后，可以参与启动后续的凋亡信号。讨论F A S时，应结合受体、配体和细胞内部信号通路来理解。不能只因为在一份检测资料中看见F A S，就认定所有表达这种受体的细胞都会立即发生凋亡。

细胞内的信号还涉及一些名称较长的结构。例如，免疫受体酪氨酸活化基序通常缩写为I T A M，免疫受体酪氨酸抑制基序通常缩写为I T I M。前者常与激活性信号的传递有关，后者常与抑制性信号的调节有关。这里说的是特定基序在信号系统中的作用，不能仅凭一个活化或抑制的名称，就推断整个细胞在任何条件下都会朝同一个方向变化。

如果把一个免疫细胞的反应比作调节音量，那么免疫受体酪氨酸活化基序与免疫受体酪氨酸抑制基序所参与的过程，可以帮助我们理解促进和限制之间的平衡。但这只是理解用的比喻。真正分析实验时，还要看受体种类、配体条件、下游分子以及时间变化。记录I T A M和I T I M时，也要逐个保留字母，避免把两个缩写混成同一个词。

免疫细胞还必须到达合适的位置。黏附分子参与细胞之间以及细胞与周围环境之间的相互作用，在细胞迁移和接触过程中具有重要意义。嗜中性粒细胞进入炎症组织，需要一系列相互配合的步骤；抗原提呈细胞与T细胞进行有效接触，也涉及细胞之间的相互作用。因此，黏附分子不只是静态的标签，它们参与组织细胞活动的空间关系。

最后，我们补充一个不属于细胞名称的实体：攻膜复合物。攻膜复合物通常用M A C表示，是补体终末通路形成的一类复合物，也称膜攻击复合物。它可以在适当的靶膜上形成孔道，参与防御。自然杀伤细胞与攻膜复合物都可能与靶细胞损伤有关，但两者的组成、形成方式和作用过程并不相同，不能因为结果有相似之处就把名称互换。

现在回到最初的黏膜损伤场景。嗜中性粒细胞等成员参与早期防御，固有淋巴样细胞中的I L C 一、I L C 二和I L C 三参与不同类型的免疫调节，抗原提呈细胞把信息与后续的T细胞反应联系起来。随着反应发展，活化B细胞、生发中心B细胞、记忆性B细胞和浆细胞分别承担不同任务。理解这些名称的价值，在于知道它们处在什么环节、与谁发生联系，以及哪些名字相近却必须严格区分。
