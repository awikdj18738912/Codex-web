# 种子与生成器来源追溯

## 回溯结果

300条样本全部按 source_id、场景和目标SHA256匹配到原始 `final/train.jsonl`；精修目标文本逐字一致，审核账本均为 `review_pass`。原始 `oral_text` 与 `input` 也全部相同。旧审核的“通过”没有排除本轮发现的跨主题拼接、矛盾实体和路线问题。

首轮标出的19条源/目标问题，经原始输入和目标复看后重新归因：明确生成侧漏信息/改代码 3 条；种子与生成器共同问题 1 条；主要是原始种子文本问题 12 条；初筛误标 3 条。该归因仍由同一ChatGPT复看，尚非人工金标。

## 关键区分

- 300条里，口语源与金标完全相同 183 条；其中 119 条源文本被初审评为失败或边界。这些样本的问题在口语生成之前已经存在于种子文本，或生成现象根本没触发。
- 另有 117 条口语源不同于金标；其中 64 条被初审评为失败或边界。改写本身也会制造不自然或失真的输入。
- 三条明确的生成器错误是：漏掉原种子中已有的事实、漏掉产品规格、改写 shell 命令中的引号字面量。应加强口语生成后的硬校验。

## 复核队列

- 种子文本/未触发风险：120 条，见 [seed_text_risk_queue.jsonl](seed_text_risk_queue.jsonl)。
- 口语改写风险：67 条，见 [oral_generation_risk_queue.jsonl](oral_generation_risk_queue.jsonl)。
- 风险队列是筛查材料，不是自动删除清单。

## 判读限制

首轮把“金标里有、口语源里缺失”表述成了“金标新增信息”，混淆了目标错误和生成源漏信息；相关记录已在本追溯中纠正。初审的19条不应直接解读为19条金标错误。
