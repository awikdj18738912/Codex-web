# 300条独立盲审结果

样本量：300；六类各50条。复核时隐藏类别、场景、原始ID和教师评审，审完后再揭示类别。评审者为当前对话中的ChatGPT，与Qwen生成模型独立；这是独立模型审查，不是人工金标。

## 总体统计

- 源文本：通过 117，边界 83，不通过 100。
- 首轮标记潜在源/目标配对问题 19 条；追溯后确认其中3条是明确口语生成漏信息/改代码，1条混合问题，12条主要是种子文本问题，3条为初筛误标。不能把19条都称为金标错误。详见 [来源追溯裁定](source_trace_adjudication.md)。
- 目标精修：漏修 115，部分修复 45，过度修改 4。
- 重大问题标记 124 条；源文本与目标完全相同 183 条。
- 在应产生变化的五类中，133/250（53.2%）源文本与目标完全相同，精修监督信号不足。
- `clean_passthrough` 的50条本来就应保持不变，但其中31条源文本被评为失败或边界，说明问题也存在于作为种子的“干净目标”池。

## 按试产分层比例校正的粗估

由于抽样时六类各50条，整体原始计数不是按5,000条中的类别比例加权。按4,989条有效候选的实际类别占比校正，估计源文本明确失败约 **33.7%**、边界文本约 **26.4%**、首轮配对风险标记约 **6.6%**（不等同于实际错误率）、标记有重大问题约 **42.2%**；源文本与目标完全相同约 **54.1%**。这些是每类仅50个样本下的模型审查粗估，不是全量验收结果。严格按“源通过且目标通过”计，样本中仅115/300条符合（分层加权约39.0%）。

## 主要失败模式

1. 不相干主题、实体或地点被拼接，常见于城市路线、产品实体和技术项目。
2. 自我修正没有收敛到最终意图，或把源文没有的信息写进目标。
3. 实体释名和否定对比过度，生成出“不是A、不是B”的提示词式口语。
4. 个别目标改变了实体、数字语义或命令行为；例如口语源漏掉原始口语中已有的退货条件/产品规格，以及改变 shell 命令参数。

## 判读限制

此审查可用于发现明显失败模式，但同样属于模型判断。边界项和疑似事实错误应由人或另一位独立审查者抽核；分层样本不代表精确的全量验收率。
