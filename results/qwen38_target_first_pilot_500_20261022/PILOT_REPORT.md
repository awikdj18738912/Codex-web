# 5,000条目标先行口语增广试产（2026-10-22）

已生成5,000条候选，没有导入现有训练集。候选目标从审核版数据的train split抽取，未使用validation目标；5,000个目标唯一。首批500条耗时约5.9分钟，新增4,500条耗时约35.0分钟，总生成耗时约40.9分钟。数字、日期、金额以及英文/代码片段的硬校验拒绝11条，剩下4989条有格式有效的口语候选。

新增批次按六种口语现象分层抽取100条，教师联合审核中99条返回有效结果：源文本89条通过，原目标86条通过，当前精修提示词输出81条通过。按相同精修目标，对旧流水线口语和目标先行口语做55对有效比较，目标先行方法在源连贯、目标保留和精修输出通过三项上分别多8、8、9个“仅本方法通过”的样本，旧口语源分别多3、3、8个。该结果初步支持新做法，但评审仍由同一Qwen3.8教师完成，不能视为人工确认或全量验收。

分层样本中的现象标记触发率不均：填充词较高；连续重复改口和意外断句较低。具体诊断见JSON报告。共有135条样本同时通过源和目标的教师审核，已单独保存为试产候选；它们尚未转换或合并进SFT训练集。
