# 免疫系统未替换原因分析

这是只读诊断，未修改代码、词库或阈值。依据原本的完整回放结果，以及对保存文本重新执行候选检索；后者不是每个原始时刻的因果追踪。

## 已确认的入口问题

数据库31项，16项是2–24纯汉字名称；另外15项含字母、数字或希腊字符且没有中文别名，被当前纯汉字正则排除。

被排除：ILC1、ILC2、ILC3、γδ T细胞、B1细胞、αβ T细胞、B2细胞、T细胞受体、B细胞受体、祖B细胞、初始B细胞、活化B细胞、生发中心B细胞、记忆性B细胞、FAS。

依据：system/entity_audio_repair.py:209、:45；system/entity_direct_spelling.py:53、:85。即使修复开启且这些条目启用，当前候选路径也不支持它们。这不是相似度阈值太高或ASR没有听见。

## 词库表达和加载

本次自动建库只注册主名称，aliases数量为0。清单中的缩写、英文读法、希腊字母读法未进入等价名称映射。实验通用加载器experiments/scripts/evaluate_entity_ctc_fusion.py:27还直接构造空aliases；当前库本身为空，因此未另造成这次结果差异，但它会影响以后补别名的实验。

例如T C R受体→TCR或T细胞受体、B一细胞→B1细胞、伽马delta T细胞→γδ T细胞，属于混合文字/读法归一，中文拼音比较无法自动完成。

## 已能召回但不满足直接规则

- 中心粒细胞→嗜中性粒细胞：5字→6字，既少“嗜”又有xin/xing差异。直接路径只支持同长度、最多一个音节一字母差，不支持增字；本次无“中性粒细胞”标准简称别名。重新检索局部上下文可召回，分数0.795，边界检查未报冲突，明显领先同跨度其他粒细胞候选。因此不能说是没找到词或简单边界拦截。
- 粘附分子→黏附分子：4字同长度，局部分词边界正常，但当前默认拼音给粘为zhan、黏为nian，差不止一个字母，直接规则拒绝。局部检索分数0.86，可走原音复核。这体现默认单字读音未结合专业语境，不表示真实发音不同。

上述两处ASR原文首次可见进度约132秒、756秒；本次复核窗口分别有123–132秒、745–760秒的区间。窗口相邻/重合不证明该候选确实作为提示词参与，日志没有逐次候选提示及复核完整输出，不能判断最终失败是重识别未给规范拼写还是锚点核验拒绝。

## 其他不能简单直接替换的项

- 哪一比较初始B细胞：当前只注册“初始B细胞”，没有naive B读法映射；名称本身含B被入口过滤。原文后半段已经含“初始B细胞”，仅检查canonical存在会错误地宣布整处正确；也不能无条件删掉前面的词。
- FAST→FAS：当前英文实体被过滤，且多一个T的差异不属于汉字同音。需要独立英文token边界及受控缩写/读法规则，不能把任意含FAST的长词截短。
- ATM→ITAM/ITIM、HLA会议→HLDA会议：必须区分对应位置，不能全文单一映射。数字/字母空格与真正字母缺失应分开处理。

## 调度因素和证据边界

本次18个复核窗口完成、errors=0，但有预算拒绝318、medium预算拒绝8561、窗口过大26、未映射87。均是重复运行的计数，不是这么多个不同实体错误。中等分数预算最多约150秒，本次已用150秒；总复核257秒。因此可达预算上限影响后续候选；不能将聚合计数精确归因给某一个词。

音频超过16秒，不做全音频收尾复核；本次short_finish_checks=0，结束时还有7个候选记录。这解释了为什么录音结束不会再补齐所有遗漏，但不是字母实体被过滤的原因。

## 优先改进顺序

1. 让规范词与候选入口真正支持中文、英文、数字、希腊字母混排，并明确单词边界。
2. 将清单中已确认的正常简称、同义名称和读法作为独立的等价映射；修正实验词库加载器，不加入ASR错写硬编码。
3. 拼音结合词级读法处理多音字；为中性粒细胞等合法简称建映射，按完整实体边界做有限缺字匹配。
4. 每次候选记录拒绝原因、提示词、复核全文和锚点拒绝细节，再针对真实瓶颈决定预算与复核策略。

31项包含本来正确、同义和格式差异，不是31个待纠正错误，因此不能用7/31作为修复准确率。
