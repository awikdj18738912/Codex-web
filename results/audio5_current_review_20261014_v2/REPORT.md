# 测试音频5：当前完整精修链路的新一轮核验

2026-10-14。完整测试音频重新识别，使用本次冻结源码的真实文件流式Web链路，再做四种同源Refiner对照。旧轮次结果没有覆盖，旧人工浏览器记录没有导入本轮。

## 当前实现如何工作

1. Qwen ASR/VAD形成完成段；文件流式会话可额外执行术语候选的局部音频回跑。本轮完整音频843.255875秒、新原始转录3955字、61完成段，主链路最终原ASR与单独新ASR逐字相同。实体音频核对实际验证一次候选，回跑26秒范围、实际解码10秒，无确认修改。

2. 完成段按标点切块，固定K=3分组。当前版本fixed_k3_context_v2，流式等待后一块作为只读右上下文，每侧只引用紧邻一个块、最多80字。只允许修改当前窗口，左右参考不得复制到正文。缓存同时检查源组和上下文，新增/改变上下文仍可能重处理；终态拒绝重跑关闭。

3. 已完成窗口先运行zh-itn-v90数字规则、实体规范化及掩码保护。数字格式归规则所有，神经Refiner不负责猜测被ASR识别错的数字值。

4. 原生tri_state门控根据稳定性、清理信号和实体提示给KEEP/DEFER/REFINE；本次未校准ASR分数不作为可靠高置信证据。原生REFINE后，当前学习窗口门控on可按冻结阈值0.8否决；它不能把原生KEEP唤醒。当前主链路confidence supplement关闭，补充分支仅作对照。

5. Refiner读取当前窗口、只读邻接上下文、实体候选，返回局部JSON补丁或兼容自由文本。兼容策略会解析补丁、恢复受保护内容，再检查数字、实体、正常重复、严重整体丢失/截断、特定替换、无依据插入及上下文复制/边界主语丢失。semantic_content_loss已移除，未按旧删字词表限制普通删除。

6. 完整性失败时按当前重试规则处理；zh-itn下纯数字完整性失败直接安全回退，不再二次生成。可独立保留安全的数字/重复/实体局部改动；流式/终态局部审核还可能补修被窗口门控跳过的内容，最后拼接最终全文。

实现入口：source_snapshot/system/web_app.py、window_refinement.py、refinement_gate.py、learned_window_gate.py、live_qwen_refiner.py、refinement_protocol.py、refinement_guard.py、entity_pipeline.py、entity_audio_repair.py。源码和匹配配置、实体SQLite一致性副本、学习模型、协议及输出指纹均保存。线上health仅用于确定配置，实际新实验从独立冻结代码加载，未假定旧进程热加载。

## 当前模块允许处理什么，实际本轮做到什么

| 任务 | 接口/实现范围 | 本轮可观察例子与限制 |
|---|---|---|
| 口吃与重复 | 相邻重复、词内口吃、局部确认删除；强调/正常叠词另保护 | 全量W120让让渡→让渡、W133机制重复合并；当前W028仍留孟孟子/争争论，W114仍留首首先 |
| 非必要填充词 | 呃/嗯等及部分表达清理，普通中文删除已不按旧词表拒绝 | W118全量能去呃并保留不太好；嗯哼/对等回应有被删风险，需要用户判定 |
| 明确改口 | 候选局部补丁、旧内容删除及规则数值纠正范围 | W048春秋晚年晚期→春秋晚期，本轮真实模型能做；接话与语气是否保留仍须核查 |
| 错字/语法 | 本地字符替换与局部纠正 | 有的/得等文字变化，但没有证明稳定恢复哲学人名、术语或所有识别错误；W143出现更差改写 |
| 标点/误断句 | 当前窗口内断句修复、边界保护和只读上下文 | 全量W068取决于。你的相信→取决于你的相信；W156当前能修能够。帮能够帮助 |
| 实体纠正 | 候选词库、确认补丁、别名、音频局部验证 | 本轮术语音频候选未被确认，无新增纠正；没有词库和声学证据时不能承诺修好错人名 |
| 数字格式 | 上游zh-itn规范化与受保护表面恢复 | 规则处理，与神经Refiner精修收益分开；不得用格式成功代替数字值正确性 |

这些是允许的任务和本次可观察行为，不是能力或正确率保证。模型能输出一个改动、保护接受一个改动、用户认为改动必要且正确，是三个不同判断。

## 如何核验

[打开新核验页](http://127.0.0.1:8086/review.html)，可以按窗口编号跳转、筛选当前跳过/拒绝/改动/跳过但全量改动，逐项查看原ASR、数字实体规则结果、实际窗口结果、全量对照、当前终态、真实只读上下文、模型原提议与拒绝理由。

每条有三项独立判断：窗口是否需要精修、当前结果是否合理、全量对照改动是否可接受。目标文字、备注和听音勾选不预填；保存于当前浏览器，导出audio5_current_review_labels.jsonl。所有窗口都列入队列，不仅展示模型有改动的窗口，避免漏掉模型本身未修的需要精修内容。
