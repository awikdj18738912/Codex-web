# 中文口语精修：生成与审核共用标准 v1

目标是表达说话者最终要传达的意思，清除无意义口语冗余。审查者必须同时阅读完整原文和候选；不能单看目标是否流畅。

## 改口与经历

- 明确纠正同一事项时，用最后确认项替换被撤回项，删除纠正过程。不要把“本来想说A，后来改成B”重写成实际做过A。
- 原文明确已经发生的事件应保留，例如“先试A失败，后来用了B”。真实尝试、方案比较和最终选择可以同时存在；不能因为最后提到B就删掉前面的真实经历。
- 暂缓表示稍后处理，不等于永久取消；新增话题不等于撤回前一个独立事项。
- 纠正作用范围无法确定时保留原文的不确定性，不猜测唯一目标。原文本身互相矛盾且未解决时，标记歧义并隔离，不能补事实使它合理。

## 有效信息

保留未被撤回的独立事情、请求、理由、条件、后果、提醒，以及有意义的疑问、否定、强调和不确定程度。清理数字或名称纠正时，纠正之后的理由和提醒仍须保留。不能从订单号推断日期，不能补人物职务、团队、因果或执行结果。按照原文评判，不用外部知识替说话者更正技术或地理事实。

## 可删除的辅助信息

无意义填充、口吃、重复、未完成起头以及只用于识别名称的拼音和拆字提示可以删除。候选保留正确名称后，删掉“温是温暖的温”不算丢失人物；写明某人在作品里任官，已能表明是人名。若用户实际请求解释读音、字义或区别，则解释本身是有效信息，不能机械删除。

## 表达与边界

保留自然口语表达的多样性。删“了”“吧”、压缩重复的“大概……左右”等同义整理不应单独判差。明显误断可接回原句，但正常独立短句、问句、感叹和代码内部标点须保留。仍有效的英文名称、型号和代码原样保留；普通描述性英文词与专名需区分。数字格式交给外部规则，精修仍须理解哪个数值是最终确认项。

## 对照例子（仅说明标准，不作为训练数据）

| 类型 | 原文 | 合理处理 |
|---|---|---|
| 连续改口 | 本来想说周二，不对，周四，还是周五吧。 | 周五吧。 |
| 真实尝试 | 我周二试过，没成功，周五再试。 | 保留周二失败和周五再试。 |
| 数值及后果 | 应该是7.3，不是7.03，小数点错了会影响预警精度。 | 保留7.3及精度提醒，删除废弃数值。 |
| 暂缓 | 合同先不处理，明天再看；今天先修回声。 | 保留合同暂缓及今天修回声。 |
| 独立事项 | 帮我设闹钟，还有查一下药店。 | 两个请求都保留。 |
| 不确定 | 好像之前设过睡眠模式。 | 不改成确定的“之前设过”。 |
| 辅助辨名 | 温知微，温是温暖的温。 | 可直接保留温知微。 |
| 实际解释请求 | 请解释温知微三个字分别怎么写。 | 解释请求须保留。 |
| 合法短句 | 我到了。你在哪里？ | 保留句界和问句。 |

## 评级

- PASS：最终意思与有效信息保留，必要清理基本完成。允许同义表达、自然口语和轻微文风差异。
- MINOR：最终意思正确，但纠正过程、废弃候选或冗余仍残留，或局部轻度语气损失。例如“183，不对，是530”最终明确530，应区分清理不全与最终值错误。
- FAIL：最终实体、数值、关系、时间、否定、操作或请求错误；遗漏有效独立信息；添加无依据事实；严重清理错误。
- AMBIGUOUS：原文存在实际且未解决的歧义，无法形成可靠唯一参照。多次改口但最后清楚不应自动判歧义。

相同候选应同评级并判持平。FAIL需指出实际原文证据；所有引文为连续逐字片段，不拼接省略号。成对胜负只看语义保留和必要清理，不按长度或文风选赢家。原始审查及后续主代理裁定分别保留，避免悄悄改变验收尺度。
