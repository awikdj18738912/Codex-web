# 改口范围专项验证

## 本轮改动

生成与审核共用标准已整理到 `pipeline/configs/refiner_quality_standard_zh.md`。该标准区分废弃候选与实际经历、独立事项与背景、辨名辅助与实际解释请求，并统一PASS/MINOR/FAIL/AMBIGUOUS的含义。

只修改了中文提示词的改口段落：最终确认明确时直接输出确认内容，删除候选和纠正过程；区分“本来想说”的选词变化与真实经历。其余提示词、模型、温度、输出预算和思考模式保持一致。候选快照在prompts_after.json；上一版在prompts_before.json。

## 60条回归结果

两组都使用Qwen3.8-27B AWQ INT4；旧输出为上一轮586字符中文提示词生成的结果，新输出为本轮661字符提示词结果。60条均生成成功并完成匿名盲审，主代理检查差异和失败项，5条显式裁定保留。格式检查、完整覆盖、输入和目标对齐及引文连续性核对通过。

| 评级 | 上一版 | 本轮候选 |
|---|---:|---:|
| PASS | 53 | 56 |
| MINOR | 7 | 3 |
| FAIL | 0 | 1 |

成对比较：本轮候选胜3、上一版胜1、持平56。44条逐字相同，16条输出改变。

改善：#7删除被撤回的第6家候选；#41删除冗余辨名提示；#119清理关键/核心作用等纠正过程。回退：#92再次删去“还是改回芒果TV”的最终纠正，从MINOR退至FAIL。#162的有效精度提醒仍保留。#176两版都残留未采用的备用电源优先建议。

**候选未通过扩大验证条件。** 虽合格数增加，已知难例出现语义回退。候选已归档，生产提示词恢复为prompts_before.json对应版本，恢复前检查了文件哈希，避免覆盖并发修改。正式训练集没有修改。教师服务在生成结束后关闭。

审查模型仍曾把辨名辅助误判为必须保留的事实，也曾声称只有一边重复而两边实际都有同一句。主代理裁定记录在regression_60/lead_adjudications.jsonl，原始盲审文件保留。不能把这些模型辅助评级视为人工专家真值。

## 新样本准备状态

fresh_sample_200.jsonl含100条剩余训练池随机样本，加5类候选各20条；排除前面实验使用的1299个ID。样本和源数据哈希、逐条manifest对齐以及选样说明在fresh_sample_manifest.json。existing_target仅留档，不得传给教师。

这200条已准备，**尚未生成或审核**，因为60条回归未通过扩大条件。它们来自现有训练源，属于新的开发验证样本，不是最终未见真实ASR测试集。

## 文件入口

- validation_decision.json：本轮决策与配置状态。
- regression_60/report.json：评级及成对结果。
- regression_60/comparison_final.csv：完整输入及两版候选。
- prompt_change.json：提示词前后及恢复的哈希。

本轮证据支持继续使用较保守版本，并将歧义原文和审核标准作为下一步重点；不支持继续按合格数单独挑选提示词或启动全量重新生成。
