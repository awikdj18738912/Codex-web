# Qwen3.8-27B 教师对照试验

目的：比较现有 Qwen3-30B-A3B-Instruct-2507 AWQ 与候选 Qwen3.8-27B AWQ 的中文口语精修，评估最终意图、内容保留、清理程度及正常输入误改。

## 模型与运行

- 候选原模型：[Qwen/Qwen3.8-27B](https://huggingface.co/Qwen/Qwen3.8-27B)。
- 实际运行权重：`cyankiwi/Qwen3.8-27B-AWQ-INT4`，固定 revision `e3a700906e6a73ba4290b1873dc2ba8198527ab5`；这是社区混合精度4bit量化，不是官方BF16原精度。
- 存储：`/home/aim0/data/ASR/models/Qwen3.8-27B-AWQ-INT4`。
- 只使用 GPU0；保留其他项目的服务。运行环境沿用已有 agentic-asr 的 vLLM 0.26.0，不修改环境依赖。
- `run_when_downloaded.py` 等待下载完成，确认GPU0空闲后启动独立端口8012。先试跑10条，若输出解析失败停止；否则继续至200条。生成结束后关闭本次教师服务并输出匿名比较文件。

## 固定对照条件

`sample_200.jsonl` 使用上一轮1000条诊断样本中的前200条。按ID匹配旧教师的实际输出（不是历史训练标签），并核对输入逐字一致。提示词逐字取自旧教师生成时的 provenance 快照。

候选关闭思考模式；temperature=0、top_p=1、max_tokens=768、JSON输出与旧实验一致。启动前计算完整聊天模板的token长度，确保输入加输出预算不超过上下文，不截断输入。两模型的量化实现和推理框架版本不同；不能把结果解释为原精度架构能力的完全隔离实验，也不能直接将不同批次并发下的耗时当作公平速度排名。

## 审查与解释

生成成功率只衡量请求和格式。须按 `review_rubric.txt` 独立盲审，再由主代理核对FAIL和分歧案例。原文确实有歧义时隔离，不强造金标准。

这些样本来自训练集诊断样本，不是最终未见测试集；不能用通过比例估计真实用户准确率，不能用这次结果宣布学生微调效果。

当前阶段读取 `experiment_status.json`；下载信息读取 `download_provenance.json` 和 `download.log`，生成进度读取 `generation_progress.json`。所有实验结果独立保存，正式数据、精修提示词和训练权重未被覆盖。

## 完成结果

200条全部生成、格式错误0；全部完成Luna匿名盲审，主代理逐字核对差异及失败案例，保留26条显式裁定记录。原始审查未改；三组二次意见另存。审查中曾出现对文本内容误读、把同义压缩判差等错误，最终裁定修正了这些问题。

成对比较：Qwen3.8胜16、旧教师胜3、持平181。通过数增加主要来自清理改口和识别辅助信息，不代表严重语义错误已减少。

新候选两条FAIL：

- #92：删掉最终“改回芒果TV”的纠正，仍把风扇设定写为有效操作；旧教师保留最终纠正但过程未清理，MINOR。
- #162：删掉“小数点不能错，否则影响结构疲劳损伤早期预警精度”的提醒及后果；旧教师保留，PASS。

旧教师一条FAIL：#119将完整英文技术名称换成中文；新候选保留名称。具体完整文本在 `semantic_failure_examples.jsonl`。

18条clean_or_passthrough分层样本中，旧教师改动5条，新候选改动2条；两者均未判出语义问题。这一分层不是人工确认的门控负例。

生成耗时1355.3秒（约22.6分钟），约8.85条/分钟，含首次内核编译；GPU0有其他项目占用，使用约3GiB CPU权重卸载，不能据此对模型做公平速度排名。所有5个权重分片SHA256与下载源匹配，见 `weight_integrity.json`。测试后本次教师服务已关闭。

**结论：值得继续验证，但暂不全量替换。** 新候选在这200条上清理更充分，严重语义错误并未显示减少。需要固定难例和真实中文ASR文本的后续验证；本轮未测试它能否作为可靠审核者，也未测试thinking或BF16模式。原训练集未修改。

结果入口：`comparison_report.json`、`comparison_final.csv`、`comparison_final.jsonl`。`report_supplement.json`记录本次时序、对照组统计及限制，汇总脚本会合并它，避免重跑时丢失说明。
