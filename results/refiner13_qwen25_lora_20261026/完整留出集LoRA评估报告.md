# LoRA 完整留出集评估

日期：2026-10-27。原始 Qwen2.5-0.5B-Instruct 与 LoRA 使用相同的 1,902 条冻结留出数据、提示词和贪心解码。留出标签仍来自待人工审核候选，场景没有与训练集隔离，因此这些数字衡量的是对候选参考的匹配，不是人工金标准确率，也不能直接代表真实 ASR 泛化。

## 整体结果

LoRA 相对基座大幅提高了对本轮合成及公开候选答案的匹配，且占位符和英文片段的自动检查均为零差异。不过 E07 仍有 13/147 条干净输入被改写。参考答案本身存在噪声：抽样看到的公开 E07 中有一条把疑似错字“资本丰义”也作为正确文本，模型照抄会被判匹配，反而说明这项指标会受标签质量影响。

逐条精确匹配转移：基座未匹配、LoRA 匹配 1,339 条；基座匹配、LoRA 未匹配 9 条；两者都匹配 336 条；两者都未匹配 218 条。这些计数依旧以候选 reference 为判定标准。
