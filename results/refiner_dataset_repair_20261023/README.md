# 现有数据集分批修缮

目标是降低已知错误与系统性偏差，允许少量残余噪声；不要求零错误才开展数据处理。原始导出保留，修复另存版本。

复用500条试处理结果中没有被具体复核意见覆盖的记录；已确认错误和歧义优先处理，已双重复核的两条最小修补先应用到待审副本。其余实际SFT数据按500条一批处理，两卡各8并发。每批可续跑，失败留痕。原文明确才修目标；原文不可靠隔离；接口/引文校验失败留待复核，不等同语义错误。

源输入/目标哈希、原划分与分组信息保留。已知具体问题即使教师再判通过也会进入修复或隔离，不用其通过结论覆盖已确认问题。

当前一轮约每500条25分钟，整批粗估3–4天，随复杂度、重试和修复比例变化。progress.json为已完成批次；当前批次细进度在outputs/batch_XXXX.progress.json。

处理完成后形成新的候选训练/验证版本；按类别抽查严重信息错误、清理不足及误改，分别报告模型过程通过率和独立抽查结果。接受残余错误不意味着默认接受未解决的重大事实/编号错误。重训先做低学习率全量与LoRA小规模对照，以生成质量和忠实度选检查点。
