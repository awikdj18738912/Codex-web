## 使用

`inference_inputs.jsonl` 只含音频和独立词库路径；`references.json` 仅用于评分。`baseline_raw.jsonl` 保存逐条原始 ASR 输出及采集来源。实体模块评估应固定这份名单，配对比较原始输出和模块输出。

## 范围

50% 是整套数据的实体提及加权命中率，不代表每个领域均为 50%。无目标实体录音未参与主集配额。这套数据依据当前 ASR 的失败筛选，属于难例压力评测；不能用来推断自然流量准确率。

AISHELL 项采用官方 NER；SpeechIO 项为参考支持的专名和术语词库匹配；CMeEE 项是医学词表到音频参考的匹配。所有来源均保留来源记录和标注方法，未声称逐条人工听审。部分音频片段来自同一原始节目，后续训练与评估应按 source_group 隔离。

独立评估词库从全部候选的参考词条构建，含未选录音支持的干扰词；推理不传参考文本。音频与词库仅用于本地评测，SpeechIO 镜像许可不代表底层节目的统一再分发许可。

[SpeechIO 官方](https://github.com/SpeechColab/Leaderboard) · [AISHELL-NER 官方](https://github.com/Alibaba-NLP/AISHELL-NER)

## 核验与来源数量

主集保留 310 条原基准音频，补入 1690 条相对原基准新增的音频；按 PCM 哈希判定。共 1671 个唯一实体、2658 次标注提及；1106 条录音至少有一个原始 ASR 实体错误。

`audio/` 包含 2,000 个 16 kHz 单声道 IEEE_FLOAT32 WAV；其数据段与评分所用原 PCM 逐字节一致。`domain_summary.csv` 是领域统计，`sample_comparison.csv` 是逐条参考与纯 ASR 对照。

核验命令：`PYTHONPATH=.:.runtime/functional_test_deps python experiments/scripts/verify_entity_challenge_dataset.py`。核验结果保存为 `verification.json`。

`source_snapshot/select_entity_challenge.py` 保留实际导出这份数据时的脚本版本；工作区脚本后续仅优化了新词库的批量写入方式。`metadata/` 保留来源登记和词表审核记录；两项影视角色的审核结论见 `review_addendum.json`。
